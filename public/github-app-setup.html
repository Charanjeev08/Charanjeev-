Create the Keystatic GitHub App

Temporary setup page. Click the button while logged in to GitHub. GitHub opens with everything filled in. Check the name and click Create GitHub App.

After you click Create

  1. GitHub sends you back to the homepage. That is expected. Go to github.com/settings/apps and open the new app.
  2. Copy the Client ID. Click Generate a new client secret and copy it.
  3. Click Install App in the left menu, choose your account, pick Only select repositories, select Charanjeev-, and install.
  4. Add the values in Vercel → Project → Settings → Environment Variables (never in chat), then redeploy.
